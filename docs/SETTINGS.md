# Settings and preview

Settings apply immediately. Visual pages include a preview generated by the same native builders as the running HUD. It uses sample data, not conversations or API credentials. Select Summary, List, Bubble, Quiet or Message to inspect a surface; Play effects demonstrates its configured reminder. Hide collapses the preview to give controls more room.

## What changes which surface?

| Setting | Scope |
| --- | --- |
| Appearance: theme, type, opacity, colors | HUD surfaces; notices remain readable on an opaque shell |
| Main bubble layout | Summary header only |
| Bubble density | Padding and gaps in the main bubble, task rows and detached bubbles; layout, type and fields stay unchanged |
| Task list style, details | Expanded task list only |
| Task names | List identities and detached bubble identities |
| Detached bubble fields | Detached bubbles only |
| Main status dot | Summary dot; task dots keep their own state and effects |
| Corner drag on the main bubble | Extra padding and spacing, above the selected layout's defaults |
| Corner drag on a detached bubble | That bubble's size |

## General

Language, position, topmost and click-through control the running HUD. Token totals selects the latest task's counts or the sum of visible tasks; it does not filter the task list or multiply account allowance. Inactive retention hides ordinary tasks after inactivity; waiting tasks and running turns have separate retention rules. Completed-task retention and departure effects act after a terminal event.

Number format applies to token numbers, including the activity rhythm total. A blank pricing path selects the bundled catalog; a local catalog changes estimates, not subscriptions or account balances. Reset restores configuration and theme selection while retaining installed theme files, pricing files and saved API keys.

## Appearance

Themes apply immediately, including imported themes. Font size, shell corners, opacity, foreground, accent and status colors preview live. A background color is the fallback for a theme that uses an image or gradient. Uniform opacity affects the whole HUD surface; layered opacity keeps text stronger than the shell; focus opacity responds to activity. Task-change fades and reminder effects are separate controls.

## Main bubble

Choose the layout here, then choose its lead: token metrics, activity rhythm or no lead. Only the relevant lead controls are shown. Task summary and account allowance remain separate sections. Cards place labels above values for metrics, rhythm, task counts and allowance groups. Vertical groups stack instead of laying out a horizontal strip. Other layouts wrap when screen width requires it.

Allowance style controls per-agent meters versus individual labeled readings. Hide missing readings removes unavailable account values, not zero balances. The waiting badge highlights tasks needing input. Extra spacing changes padding and gaps without scaling the type.

## Tasks

The default display mode can be Summary, List or Detached. The summary arrow temporarily expands or collapses the list; choosing a new mode in Settings takes precedence over that temporary state.

List style changes structure; bubble density changes padding, row height and button spacing across the HUD; list details changes the metrics shown. Compact, balanced and relaxed keep the same identity lines, typography and content. Context badges remain visible in the list; the context visibility switch controls detached bubbles.

Task numbers, names and context badges share content-measured column widths within each list, so short titles and changing percentages do not shift the neighboring columns. The settings preview uses the same spacing and column alignment as the live list, including additional corner-drag spacing. Disclosure and task action buttons share their size and corner treatment; informational badges use lighter surfaces without button-like outlines.

Detached bubbles have separate field choices and a count limit from 1 to 12. Reducing the limit merges excess bubbles. Automatic splitting applies to new tasks in Detached mode. Number reuse cooldown reserves retired task numbers and can be set to immediate reuse.

Quiet mode retracts after inactivity and expands on hover or new work. A small neutral capsule replaces the full bubble; its status mark has no accent ring. Interface transitions animate the shell size and position while fading the content without stretching type. The preview can demonstrate both directions without waiting for the inactivity timer. Quiet size does not inherit the expanded bubble's extra spacing. Task-light shape is relevant only for the horizontal and vertical variants.

## Alerts

Completion, interruption/error, waiting and sustained quiet are distinct triggers. Summary, list-row and detached-bubble surface effects are independent; dot pattern, brightness, speed and breathing control the task status lights. The preview demonstrates effects locally and sends no notices to tasks.

Context alerts use per-task thresholds. Enabling alerts also enables the detached context display; hiding that display disables the alerts. Showing it alone does not turn alerts back on. Changing unrelated appearance settings preserves an existing context alert's progress.

Agent notices require the feature to be enabled. Permission, effect, color, intensity and duration configure their card. The allowance handoff guard is for Codex account allowance at agent checkpoints; it does not automatically interrupt generation or apply this guard to Claude or DeepSeek. Thresholds use remaining percentages, and handoff thresholds cannot exceed preparation thresholds.

## Agents

Source switches filter local task monitoring. Codex and Claude subscription readings are account-level values with observation times. DeepSeek balance requires a saved key; its row distinguishes pending, successful and failed reads. Account updates refresh an open settings window even when there is no visible task. The key is stored separately from the settings document.
